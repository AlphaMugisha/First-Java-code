# Happy Paws Pet Care System 🐾
**NGA Coding Academy · Fundamentals of OOP with Java**  
*Practical Assignment (100 Marks)*

---

## 📖 Scenario
Happy Paws is a pet care centre in Kigali that grooms pets and finds homes for street dogs and cats. The manager, Mrs. Uwase, hired a junior Java developer to replace her paper notebook with structured Java programs.

---

## 📂 Project Structure & Tasks

All assignment files are organized in the `assignment 1/` directory:

| Task | File | Description | Marks |
| :--- | :--- | :--- | :--- |
| **Task 1** | `assignment 1/Pet.java` | Class `Pet` (name, type, age) with `greet()` method | 10 |
| **Task 2** | `assignment 1/Customer.java` | Customer registration using `this` constructor | 10 |
| **Task 3** | `assignment 1/PetHealthRecord.java` | Bobby's medical record using appropriate Java data types | 10 |
| **Task 4** | `assignment 1/Staff.java` | Demonstration of static, instance, and local variables | 10 |
| **Task 5** | `assignment 1/GroomingBill.java` | Arithmetic calculations: totals, change, division, and increments | 15 |
| **Task 6** | `assignment 1/FoodStock.java` | Step-by-step compound assignment operators (`+=`, `-=`, `*=`, `/=`, `%=`) | 10 |
| **Task 7** | `assignment 1/AdoptionCheck.java` | Adoption eligibility checks using logical operators (`&&`, `\|\|`, `!`) | 10 |
| **Task 8** | `assignment 1/HappyPawsReceipt.java` | Mini-project: visit counter, discount calculation, and free treats | 25 |

---

## 🚀 How to Run

### Method 1: 1-Click Runner (Windows)
Double-click `run_all.bat` inside the `assignment 1/` folder to compile and run all 8 tasks automatically in the command line.

### Method 2: Command Line
Navigate to the `assignment 1` folder:
```bash
cd "assignment 1"
javac *.java
```
Run any task:
```bash
java Pet
java Customer
java PetHealthRecord
java Staff
java GroomingBill
java FoodStock
java AdoptionCheck
java HappyPawsReceipt
```
